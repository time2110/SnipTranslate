# SnipTranslate 安装包制作与使用

## 一条命令生成安装包

在项目根目录打开 PowerShell，运行：

```powershell
.\scripts\Package.ps1
```

如果系统禁止执行本地 PowerShell 脚本，可使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1
```

指定版本号：

```powershell
.\scripts\Package.ps1 -Version 0.2.0
```

首次运行时，如果电脑没有 Inno Setup，脚本会从 Inno Setup 官网下载安装程序、验证发布者数字签名，然后为当前用户静默安装。后续打包不会重复安装。

脚本会自动完成：

1. 检查并下载 RapidOCR 模型。
2. 发布 Windows x64 自包含主程序。
3. 发布自包含 OCR Worker。
4. 收集 OCR 模型和本地依赖。
5. 使用 Inno Setup 压缩并生成安装程序。

生成结果位于：

```text
artifacts\installer\SnipTranslate-Setup-0.1.0-win-x64.exe
```

自包含安装包不要求目标电脑预先安装 .NET，但只支持 64 位 Windows。

## 安装和卸载

双击生成的安装包，根据向导安装。默认安装到：

```text
%LOCALAPPDATA%\Programs\SnipTranslate
```

安装不需要管理员权限。安装向导可以选择创建桌面快捷方式和开机启动。

卸载方式：Windows 设置 → 应用 → 已安装的应用 → SnipTranslate → 卸载。

安装时可以勾选“登录 Windows 时自动启动”。安装完成后，也可以在托盘 → 设置中随时开启或关闭“开机自动启动 SnipTranslate”，该功能只作用于当前 Windows 用户，不需要管理员权限。

用户代理设置存放在 `%LOCALAPPDATA%\SnipTranslate`，其中代理密码使用 Windows DPAPI 加密。卸载程序默认保留用户设置。

## 使用说明

启动后程序常驻系统托盘：

| 操作 | 功能 |
|---|---|
| `F1` | 普通截图（可在设置中修改） |
| `Ctrl+F1` | 截图并自动 OCR、翻译（可在设置中修改） |
| `O` | 对当前选区执行 OCR |
| `T` | 对当前选区执行 OCR、翻译 |
| `Esc` | 立即关闭全部截图遮罩和 OCR/翻译卡片，返回后台托盘 |
| `P` / `R` / `A` / `X` | 画笔 / 矩形 / 箭头 / 文字 |
| `Shift` | 切换放大镜 HEX/RGB 格式 |
| `C` | 复制放大镜当前颜色值 |
| `Enter` | 复制截图 |
| `Space` | 贴图 |
| `Ctrl+S` | 保存 PNG |
| `Ctrl+Z` | 撤销标注 |
| `Esc` | 退出当前工具或关闭截图 |

鼠标悬停时会自动高亮当前窗口，单击即可选择整个窗口；直接拖动仍是自由框选。OCR 结果在截图选区旁显示。点击结果卡片顶部的“翻译”即可翻译现有 OCR 文本，不会重复识别。设置中可选择中英日通用、英文优先或韩文 OCR，并启用旋转文字识别。翻译默认使用 Google Web，可在托盘设置中切换微软/Bing Translator、LibreTranslate、MyMemory 或自定义 HTTP API，并配置系统代理、直连或自定义代理。

微软/Bing Translator 需要 Azure Translator API Key，区域资源还需填写 Region。LibreTranslate 可连接公共或自建实例，API Key 视实例要求填写。MyMemory 可免 Key 使用，但有公共额度限制。自定义 API 使用 POST JSON，请求模板支持 `{text}`、`{source}`、`{target}`，译文路径可填写 `translatedText`、`data.translatedText` 或带数组下标的路径。

翻译 API 列表支持添加、独立编辑、启用/停用、删除和拖动排序。每个条目分别保存名称、接口类型、地址、Key、Region 或自定义 JSON 模板；编辑后点“保存此接口”。“测试翻译”只请求当前选中的接口。启用自动切换后程序从上到下尝试，发生限流、超时、网络或响应错误时自动切换下一项，并在 OCR 结果卡片中标明实际服务及“自动切换”。429、鉴权失败或连续故障会让接口暂时进入冷却状态。关闭自动切换时只请求列表中第一个已启用接口。

## 常见问题

### Google 返回 429

表示当前出口 IP 请求过于频繁。程序会自动短暂重试并切换备用 Google 入口；仍然失败时，请稍后再试或在设置中更换代理节点。OCR 本地识别不受影响。

### F1 没有反应

可能被其他软件占用。可以从系统托盘进入设置，点击快捷键输入框后直接按下新的组合键。

### Windows 显示未知发布者

当前安装包没有商业代码签名证书，因此 Windows SmartScreen 可能提示未知发布者。正式分发时应购买代码签名证书，并在打包后使用 `signtool.exe` 对安装包签名。
